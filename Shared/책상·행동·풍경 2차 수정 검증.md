# v0.5.9 책상·행동·풍경 수정

2026-11-06 사용자 요청 10항목을 Windows·Mac·웹에 반영했다.

- 소품: 기존 12×12 확대 그림을 제거하고 책·노트북 오른쪽 x=36~42, 바닥 y=26에 배치. 명패·스탠드·음료와 분리했다.
- 음료: 아이스커피와 머그·맥주잔의 옆면 윤곽을 연결하고 맥주잔 밑면을 평평하게 했다. 오른쪽 배치와 마지막 전경 레이어를 유지한다.
- 의자: 공통 도안 3개, 선택 항목, 렌더링을 제거했다. 저장된 의자 값은 파서가 무시한다. 도안 수는 61개다.
- 조명: 8종 스탠드의 빛이 각 광원에서 책·노트북 중심 x=29로 향한다.
- 책 넘김: PageLift→TurnPage→PageSettle. 12초 주기의 평상시 필기에서도 2.25초 동안 재생하고, 읽기 행동에는 3초의 넘김 구간을 둔다.
- 일상 동작: 기존 90초 간격을 30초로 줄였다. 12종은 6분에 한 번씩 모두 재생한다. 노트북에서 연필·생각·펜 돌리기 등을 RestHands로 덮어쓰던 처리를 제거했다. 웹에도 공통 12종 자세 순서를 연결했다.
- 동작 중단 원인: 기기 동기화의 ApplySync가 같은 상태에도 SetMood를 호출하여 시간을 0으로 초기화했다. 같은 상태는 다시 그리기만 하며 동작 시간을 유지한다. 25초마다 8번 같은 상태를 받고 205초에 하품하는 검사와 실제 휴식 전환 검사를 추가했다.
- 자리 비움: 굵은 글꼴, 표지판 내부 중심 x=11·y=5.5로 정렬했다.
- 바닥: 벽과 바닥 사이에 2px 걸레받이·윗면 밝은 선을 추가했다.
- 풍경: 등대 빛을 창 오른쪽까지 넓혔다. 겨울 나무 배경에 눈 둔덕과 음영, 정원에 나무 울타리를 넣고 눈발 밀도를 줄였다. 밤의 바다·호수는 하늘과 다른 청록색이다.
- 시계: 원의 네 끝에 남던 돌출 픽셀을 없앴고 12개 눈금을 내부에 배치했다.
