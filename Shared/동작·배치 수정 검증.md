# 동작·책상 배치 후속 수정 — 2026-11-05 (미배포)

사용자 피드백: 가방을 챙길 때 숙인 머리와 늘어나는 팔, 끊기는 이동, 의자 없음 선택, 노란 조명, 음료 가림, 좁은 책상과 컴퓨터별 자리 간격, 책상 아래 의자, 어색한 방문 인사.

- Windows·Mac·웹 가방 챙기기에 별도 Pack 자세를 사용한다. 바닥에서 물건을 줍는 PickUp 자세를 재사용하지 않는다. 몸을 일으키는 높이와 손 경로는 시간에 따라 보간하고 팔이 비정상적으로 길어지지 않게 제한한다.
- 팻말은 오른쪽에 내려놓고 인사하는 얼굴과 손 뒤에 그린다. 책·노트북 넣기와 가방 들기는 유지한다.
- 기본·흰색·짙은 원목 책상 너비는 44→52px, 높이는 38px 유지. 명패와 캐릭터 좌표는 보존한다. 책상 간격은 그림 픽셀 6칸으로 통일하고 방문자의 반전 기준은 기존 캐릭터 폭을 유지한다.
- 의자 아래 다리는 그리지 않고 등받이만 남긴다. 꾸미기 선택은 명시적인 ‘의자 없음’이며 기존 enabled 저장 형식과 잠금·랜덤 규칙을 유지한다.
- 음료는 캐릭터 머리카락·의자보다 앞에 그린다. 켜 둔 스탠드는 공부 중 낮에도 빛을 내며 노란 빛의 색과 불투명도를 높였다. 꾸미기 미리보기에서도 확인할 수 있다.
- 방문자는 상대와 더 떨어져 멈추고 보행 주기는 시간 기준으로 계산한다. 모바일은 약 30fps로 렌더링하고 출발·귀환을 보간한다. 선택한 친구 자리로 방문하며 방문 중 자기 자리에 복제 캐릭터가 남지 않는다. 공부 종료 시 방문 동작을 끝낸다.

검증

- Windows Release 빌드 성공. NuGet 취약성 서비스 접속 실패 NU1900 경고 1건이 있으며 컴파일 오류는 없다.
- 격리된 Windows 자체 검사 `obj/selftest-scene/selftest.txt` PASS. 최종 팻말 수정 재검사는 `obj/selftest-scene-final`에서 수행한다.
- 웹 회귀 검사 18개 PASS. 손 경로 연속성·팔 길이 제한·책상 너비·의자 숨김 저장·음료 앞면·8종 조명 검사를 추가했다.
- C#·웹 자세 384개, 방문 자세 384개, 시계 720개, 꾸미기 조합 896개 픽셀 비교 PASS.
- 로컬 모의 서버의 320/390px 모바일 화면, 꾸미기·자리 선택·방문·퇴장 검사 PASS. `obj/qa-customization`에 화면을 저장한다.
- Mac 코드는 반영했으나 외부 공개 GitHub 저장소로 소스를 전송하는 CI 실행이 자동 승인 검토에서 거절되어 사용자 승인을 요청했다. Mac 컴파일·실행은 아직 검증하지 않았다.

실행 중인 앱·개인 공부 기록을 변경하지 않았다. 정식 릴리스, 운영 웹, Firebase 규칙은 배포하지 않았다.
