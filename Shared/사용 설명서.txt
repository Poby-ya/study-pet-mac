## 공부 시작
공부 친구 사용 설명서

Windows: Ctrl+Alt+S / Mac: control+option+S
앱을 실행하면 과목 선택창이 화면 오른쪽 아래에 열립니다. 이미 실행 중인 앱을 다시 열어도 선택창을 앞으로 가져옵니다.
공부를 시작하기 전에는 플래너가 열립니다. 새 과목을 적고 ‘시작!’을 누르거나, 목록의 과목을 선택하세요. Enter로 시작하고 Esc로 닫을 수 있어요.
공부·일시정지 중에는 우클릭 → ‘공부 과목 변경…’으로 다른 과목을 고르세요. 고르는 동안에는 현재 과목이 유지되고, 선택한 순간 이전 과목의 기록을 저장한 뒤 새 과목의 시간을 시작하고, 책상 음료도 이전과 다른 것으로 바꿉니다. 취소하거나 같은 과목을 고르면 시간은 그대로입니다. 일시정지 중에 변경하면 새 과목도 일시정지 상태를 유지합니다.

공부 중에는 같은 단축키나 내 펫 클릭으로 일시정지·다시 시작을 할 수 있습니다.
우클릭 메뉴의 ‘최소화’로 펫과 칠판을 숨겨도 공부 중인 시간은 계속 기록됩니다. 일시정지 상태는 그대로 유지됩니다.
다시 보려면 Windows 트레이 / Mac 메뉴 막대의 펫 아이콘 메뉴에서 ‘다시 보이기’를 누르세요. 최소화한 상태에서 시작 단축키를 누르면 일시정지 없이 화면만 복원합니다.
Windows: Ctrl+Alt+X / Mac: control+option+X로 공부를 마칩니다.
일시정지는 공부 시간에서 제외해요. 노트북 덮개를 닫아 둔 시간은 포함되므로, 멈추려면 일시정지해 주세요.

창유리를 누르면 봄·여름·가을·겨울 순으로 넘어가고 매번 다른 풍경이 나타납니다. 시계는 현재 시간을 보여 줍니다.

펫을 끌면 위치를 옮길 수 있습니다. 책상을 화면 위쪽 끝까지 올릴 수 있고, 위쪽 여백은 화면 밖에 둘 수 있어요. 펫이나 트레이 아이콘(Mac은 메뉴 막대 아이콘)의 메뉴에서 기록·친구·꾸미기·크기 조정·업데이트 확인을 찾을 수 있어요.
‘캐릭터 꾸미기…’에는 캐릭터·책상·교실 탭이 있습니다. 성별·주로 쓰는 손은 버튼으로, 피부색은 색칸으로 고릅니다. 나머지는 각 탭의 ‘랜덤 뽑기’로 바뀌며, ‘고정할 것을 선택하세요’ 아래 체크한 부위는 유지됩니다. 피부색도 랜덤으로 바뀌지 않습니다. 문구 스티커와 책상 스티커는 ‘추가할 것을 선택하세요’에서 각각 켜거나 끕니다. 머리·귀·목·옷 배지는 부위별로 함께 착용할 수 있고, 책상 추가 소품은 하나만 놓입니다. 장식을 껐다 켜면 마지막 모양을 유지합니다. 가방은 기존 책가방 모양을 유지하고 색만 랜덤입니다. 필기·휴식·인사 또는 교실 미리보기를 보고 적용하세요. 작은 화면에서는 스크롤로 모든 항목을 볼 수 있습니다. 캐릭터·개인 책상은 친구에게도 보이고, 교실 배경은 연결된 내 기기 사이에서만 공유됩니다.
‘크기 조정…’에서 캐릭터, 칠판 글자, 말풍선, 닉네임 크기를 따로 바꿀 수 있어요.
창 너비는 고정한 옆자리 수에 맞춰 자동으로 줄어듭니다. 공부를 마친 캐릭터는 가방을 책상 위로 올려 책이나 노트북을 넣고, ‘자리 비움’ 표지판을 놓은 뒤 걸어 나갑니다. 이미 자리를 비운 친구의 책상에는 표지판이 놓여 있어요.
공부 중에는 응원 문구와 30분 단위 달성이 잠깐 나타납니다. 가끔 기지개를 켜고, 연필을 줍고, 차를 마시고, 하품하거나 꾸벅 졸다 깨고, 쿠키를 먹고, 펜을 돌립니다. 나비가 머리에 앉았다 가기도 합니다. 양옆 친구도 가끔 이런 동작을 합니다. 이런 동작 중에도 공부 시간은 계속 기록됩니다.

업데이트: 실행·최소화 중에는 새 버전 배포 신호를 받아 버전마다 한 번 알려 드려요. 연결 복구·잠자기 복귀·앱 시작 때도 확인하고, 정기 확인도 함께 합니다.
새 버전 안내는 8초 뒤 과목·공부 시간으로 돌아옵니다. 최소화 중에는 트레이 또는 메뉴 막대에 알림을 남깁니다. ‘업데이트 확인’을 누르면 새 버전을 설치하고 다시 시작합니다. 기존 v0.4.4는 이 개선판을 처음 발견할 때까지 기존 확인 주기를 따릅니다.
펫이나 아이콘 우클릭 → ‘업데이트 확인’을 누르면 새 버전을 설치하고 다시 시작합니다.
새 파일을 받는 동안 공부를 계속할 수 있습니다. 설치 직전에 기록을 저장하고 자동으로 재실행해 과목·누적 시간·일시정지 상태를 이어갑니다. 설치에 걸린 시간은 공부에 포함하지 않아요.
인터넷이나 설치에 문제가 생기면 ‘업데이트 확인’을 다시 눌러 안내를 확인하세요. v0.2.3 이하에서는 새 버전을 한 번 직접 설치해야 이 기능이 생깁니다.

## 플래너와 기록
플래너에는 이번 달 공부 시간 순서대로 최대 8개 과목이 나옵니다.
시간은 ‘이번 달 (전체 합계)’입니다. 긴 이름은 마우스를 올려 확인하세요.
과목이 화면보다 많으면 목록을 스크롤하세요. Tab으로 과목·삭제 버튼을 선택할 수 있습니다.

✕를 누르면 목록에서만 뺄지, 기록도 지울지 선택합니다. 기록까지 지우면 통계에서도 사라집니다. 목록에서만 뺀 과목은 다시 공부하면 나타나요.
‘기록 보기’에서 과목별·일별·월별 공부 시간을 확인합니다.

기록 저장에 실패하면 오류를 해결한 뒤 다시 시작이나 그만하기를 눌러 재시도하세요. 미저장 기록을 보호하기 위해 새 공부 시작이 보류될 수 있습니다.

## 친구와 공부하기
먼저 닉네임을 정한 뒤 ‘친구와 공부하기 → 초대 코드 넣기’에 받은 코드를 붙여 넣으세요.
닉네임·이름·추천인을 적어 가입을 요청합니다. 방장이 승인하면 자동으로 들어가요.
실명과 추천인은 가입 요청에만 사용하며 결정 후 요청을 삭제합니다.

‘친구와 공부하기 → 칠판 방 선택’에서 방장이 허용한 방 중 화면에 표시할 방을 고르세요.
볼 수 있는 방이 여러 개라면 칠판을 클릭할 때마다 다음 방으로 넘어가고 마지막 방 다음에는 첫 방으로 돌아옵니다. 칠판을 끌면 기존처럼 창 위치를 옮깁니다.
방은 칠판의 그룹입니다. 어느 방을 보고 있어도 내 과목·공부 상태·시간은 허용된 모든 방에 같게 표시됩니다. 실제 공부 기록은 한 번만 저장합니다. 인원수에는 나도 포함합니다.

‘양옆 자리 고정 → 왼쪽 자리 / 오른쪽 자리’에서 친구를 한 명씩 고릅니다. 가운데는 나이며 최대 세 캐릭터를 볼 수 있어요. 내가 볼 수 있는 방의 친구라면 다른 칠판에 있는 사람도 고정할 수 있고, 방을 바꿔도 유지됩니다. 같은 친구를 양쪽에 중복해서 앉힐 수는 없어요.

양옆 친구를 클릭하거나 ‘친구와 공부하기 → 친구 부르기’에서 이름을 고르면 깨우거나 응원합니다. 보내는 사람 화면에서도 내 캐릭터가 걸어갔다가 돌아옵니다. 받는 사람은 친구가 찾아오는 모습을 봅니다. 같은 사람은 10초에 한 번만 부를 수 있어요.
응원은 ‘오늘도 힘내!’, ‘정말 대단해!’ 등 여러 문구가 번갈아 나옵니다. 자리 비움에서 돌아온 후 첫 응원은 ‘드디어 왔구나!’, 휴식을 마친 후에는 ‘드디어 깼구나!’로 인사합니다. 응원을 받으면 잠깐 눈이 불꽃처럼 반짝입니다. 친구의 앱 버전이 나보다 낮거나 확인되지 않으면 응원 대신 ‘업데이트가 새로 나왔대!’를 전하며, 받은 앱은 공식 배포를 확인합니다. 버전 정보를 공유하지 않는 0.4.X 친구도 업데이트 문구를 볼 수 있습니다.
방문 캐릭터는 책상 뒤로 이동하고, 책상 아래로 하체가 드러나지 않습니다. 이동은 실제 경과 시간을 기준으로 부드럽게 이어집니다.
자리 비움·일시정지 중인 사람이 호출을 받으면 누가 찾는지 알려 주고 공부를 시작할지 묻습니다. 시작을 고르면 스터디플래너에서 과목을 고릅니다. 공부 중이면 응원 애니메이션만 보여 줍니다.
공부를 마치거나 종료할 때 인사하고 사라집니다. 내 양옆 친구가 공부를 마쳐도 손을 흔들고 자리를 비웁니다.

## 방장 관리
방 만들기·가입 승인·방 관리는 Windows에서 합니다. Mac 친구도 같은 방에 참여할 수 있습니다.
‘친구와 공부하기 → 방 관리’에서 ‘+ 방 추가’로 방을 만듭니다. 방장은 모든 방에 자동으로 표시됩니다.
사람 이름을 다른 방 명단으로 끌어 놓으면 그 방에도 추가됩니다. 기존 방은 유지하며, 친구는 등록된 방의 칠판 중 하나를 선택합니다.
‘선택한 친구를 이 방에서 제외’로 방 한 곳의 등록을 해제합니다. 최소 한 방은 남겨야 하고 방장은 제외할 수 없습니다.
첫 방을 포함해 방 이름을 두 번 클릭하거나 ‘이름 바꾸기’를 누르면 20자까지 수정합니다.
‘기본 입장 방으로 지정’을 누르면 새로 승인한 친구가 처음 배정될 방을 바꿉니다. 기존 친구의 방과 초대 코드는 유지됩니다.
새로고침으로 최신 명단을 불러옵니다. 방 관리의 총인원은 여러 방에 등록된 같은 사람을 한 번만 셉니다.

초대 코드는 처음 만든 방의 코드 하나를 계속 공유하세요. 새 친구는 방장이 정한 기본 입장 방에 들어옵니다.
여러 방 기능을 함께 쓰려면 방장이 먼저 v0.3.0 이상을 실행하고 친구들도 같은 버전으로 업데이트하세요. 기존 승인과 방은 방장이 실행할 때 자동으로 연결됩니다.

## 방 만들기와 연결 문제
방장은 Firebase Realtime Database 주소와 웹 API 키가 필요합니다. Firebase에서 익명 로그인을 켜고 앱에 맞는 보안 규칙을 게시하세요. 자세한 설정 순서는 프로젝트 README의 ‘방 만들기’에 있습니다.

연결이 안 되면 인터넷 연결·초대 코드·익명 로그인 설정을 확인하세요.
‘권한이 없어요’가 나오면 방장 승인과 Firebase 보안 규칙 버전을 확인하세요. 앱을 업데이트할 때 규칙도 함께 업데이트해야 할 수 있습니다.
로그인 정보가 바뀌었다는 안내가 나오면 초대 코드를 다시 넣고 재승인을 요청하세요.
서버에서 거절됐거나 연결이 끊긴 작업은 완료 상태를 확인한 뒤 다시 시도하세요.

기본 공부 기록은 각자 PC에 저장됩니다. 기기를 연결하면 같은 계정의 개인 기록도 동기화합니다. 방 친구에게는 닉네임·모습·현재 공부 상태를 공유합니다.
다른 PC나 휴대폰에서 원래 자리와 기록을 쓰려면 기존 기기에서 연결 코드를 만들어 승인하세요. 연결할 기존 기기의 로그인 정보까지 잃었다면 방장에게 재승인을 요청해야 합니다.

휴대폰에서 연결하기
컴퓨터에서 ‘계정·기기 연결 → 이 기기에서 연결 코드 만들기’를 누르세요. 공부나 휴식 중인 첫 연결이라면 공부를 마칠지 먼저 묻습니다.
휴대폰에서 https://poby-study-room.web.app → ‘계정 연결하기’를 눌러 10자리 코드를 입력하고 원래 기기에서 승인하세요.
빈 옆자리를 눌러 친구를 선택하세요. 배정된 친구를 누르면 응원·깨우기·공부 초대를 보내고, 자리 아래 ‘옆자리 바꾸기’ 버튼으로 친구를 바꿀 수 있어요. 사용법은 하단 ‘설명서’에 있습니다.

기기를 연결하면 같은 계정의 방·친구 목록을 자동으로 불러오며, 양옆에 고른 친구와 선택한 칠판도 함께 이어집니다. 친구의 가입·승인 정보는 서버에서 불러옵니다.

[디자인 안내]
캐릭터와 책상은 기존의 낮고 아담한 비율을 유지합니다. 학교 책상은 후보에서 제외했으며 새 꾸미기 도안은 64종입니다. 명패는 기존처럼 책상 왼쪽 위에 표시합니다. 교실 탭에서는 칠판·창문·바닥과 책상을 함께 미리 봅니다.
