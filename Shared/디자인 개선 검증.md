# 전체 디자인 개선 — 2026-11-05

사용자 피드백에 따라 신규 장식뿐 아니라 기존 캐릭터·기본 책상·소품·교실도 함께 정리합니다.

- **기존의 낮고 아담한 비율 유지.** 길어진 책상 다리와 새로 드러낸 캐릭터 다리는 되돌렸습니다.
- **학교 책상 제외.** 신규 선택 도안은 65종에서 64종으로 변경합니다. 이전 시험 프로필의 학교 책상 값은 기본 책상으로 복구하며 다른 선택은 유지합니다.
- 기존 22개 기본 도안: 책상 모서리·앞판, 가방 봉제선·주머니, 머그·유리컵·음료, 노트북 반사광, 기본 조명, 리본·머리핀·모자·머리카락 명암을 보강했습니다. 새 가방 종류는 추가하지 않았습니다.
- 신규 조명과 모자는 둥근 갓, 챙의 방향, 접힌 천, 고깔의 실루엣으로 구분합니다. 새 머리는 기존 머리 위에 얹는 대신 독립 윤곽으로 표시합니다.
- 소품은 축소 손실을 줄인 전용 픽셀 도안으로 그립니다. **명패 위치·모양과 기존 화면 배치는 유지합니다.**
- 교실의 창틀 간격, 밝기와 나무 바닥 이음선을 정리합니다. 커튼과 블라인드는 실제 창 크기에 맞춰 붙고, 추시계는 나무 케이스 안에 시계판과 추가 들어갑니다.
- 교실 미리보기는 창·시계·칠판·바닥·책상을 함께 보여 줍니다.
