# 꾸미기 확장과 기기 연결 복원 검증

선택한 새 도안 65종, 문구·책상 스티커 분리, 부위별 추가·고정·랜덤, 개인 교실 꾸미기와 퇴장 연결을 구현했습니다. 가방 모양은 추가하지 않았습니다.

## 완료한 로컬 검사

- Windows Release 빌드: 경고·오류 0.
- 격리된 전체 자체 검사와 모의 서버 친구 공유: PASS. 결과는 obj/selftest-customization-network-final/selftest.txt.
- PC-PC 회귀: 닉네임 없는 새 PC에 계정 프로필이 도착하면 방 두 개·친구 목록·고정한 친구·선택한 칠판을 자동 복원합니다. 이후 수신은 기존 구독을 재사용합니다. 명시적으로 비운 친구 자리는 마이그레이션이 덮어쓰지 않습니다.
- 신규 꾸미기 검사: PASS. 승인 도안 수 65, 스티커 네 조합 저장·렌더링, 비활성 항목과 고정 항목의 랜덤 제외, 잘못된 슬롯의 독립 복구, 공유 정보에서 교실·고정 상태 제외.
- 신규 Windows·웹 그림 520개와 방문자 그림 520개: 픽셀 일치. 기존 자세·방문자 각 384개와 시계 720개 비교도 유지합니다.
- 웹 기존 테스트 15개: PASS.
- 모바일 모의 브라우저: 최초 연결·승인·재접속·친구 선택·퇴장, 꾸미기 탭·저장·취소, 320/390px 화면 검사 PASS. 스크린샷은 obj/qa-customization/.
- 로컬 Firebase 에뮬레이터 5개 검사: PASS. 본인만 공유 꾸미기를 쓰며 잘못된 값, 다른 사람의 수정, 교실 설정과 고정 상태 전송을 거절합니다.

## Mac과 배포

사용자가 공개 소스 전송과 Mac 검사를 명시적으로 승인했습니다. 빌드 실행: https://github.com/Poby-ya/study-pet-mac/actions/runs/42008249628 . 최종 결과는 검사 완료 후 기록합니다.

공개 릴리스와 운영 Firebase 규칙·Hosting에는 아직 반영하지 않았습니다. 사용 중인 앱을 종료하거나 사용자 기록을 검사에 사용하지 않았습니다. 실물 iPhone·Android 검증은 수행하지 않았습니다.
